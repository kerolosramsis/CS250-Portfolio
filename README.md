## CS 250 Portfolio Reflection

### How do I interpret user needs and implement them into a program? How does creating user stories help with this?

I interpret user needs by identifying what the customer wants the software to accomplish and turning those needs into clear requirements. User stories help because they describe features from the user’s point of view and make it easier to understand the purpose of each feature. During the SNHU Travel project, user stories helped guide development by connecting customer expectations to specific functionality and acceptance criteria. This helped me focus on building features that provided value to the user instead of making assumptions about what the program should do.

### How do I approach developing programs? What Agile processes do I hope to incorporate into my future development work?

I approach program development by first understanding the requirements, breaking the work into smaller tasks, developing one part at a time, and testing throughout the process. In future development work, I would like to continue using Agile practices such as user stories, continuous testing, Sprint Reviews, and regular communication with team members. I found that these practices make it easier to identify problems early and adapt when requirements change. The SNHU Travel project showed me that Agile can help preserve working parts of a program while allowing necessary changes to be made efficiently.

### What does it mean to be a good team member in software development?

Being a good team member in software development means communicating clearly, completing assigned work, helping identify problems, and being willing to listen to feedback from others. It also means understanding how individual work contributes to the overall product. A strong team member should communicate blockers early, respect the responsibilities of other Scrum roles, and support shared goals instead of focusing only on personal tasks. Throughout this course, I learned that collaboration between the Product Owner, Scrum Master, developers, and testers is important for producing software that meets customer expectations.
